# Team-Xero Mech Royale bot (TypeScript line)

A 'mechfight/1' bot for the Builders Mech Royale track, run with the pinned Bun runtime.

## Provenance

This line starts from the MIT-licensed TTUN "r1ver" economy bot (revision
'af337d5c1275d03478685bd4936c8a551fa6b200'): 'bot.ts' and 'map.ts' are their work, and their
copyright notice and licence are kept in 'LICENSE-TTUN'. 'mechfight.ts' is the organisers' starter
wrapper. Changes made by Team-Xero on top of that base are listed in the commit history.

Team-Xero's own Rust bot lives on the 'master' branch of this repository.
