# Team-Xero Mech Royale bot (Go line)

A `mechfight/1` bot for the Builders Mech Royale track. Go, standard library only.

## Provenance

This line starts from the MIT-licensed bot by giddygiddyboy
(https://github.com/justnau/giddygiddyboy-mech-royale, commit `60d4744`). Their copyright notice
and licence are kept in `LICENSE-giddygiddyboy`. Changes made by Team-Xero on top of that base are
in the commit history. Team-Xero own Rust bot is on the `master` branch; a TypeScript line based
on the MIT-licensed TTUN bot is on `ts-econ`.
